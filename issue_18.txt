## Deskripsi
Fungsi get_setting() di settings/__init__.py line 107 melakukan import yang salah:
from database import get_db
Seharusnya: from web.database import get_db

## Lokasi
web/blueprints/settings/__init__.py, line 107

## Dampak
Fungsi ini dipanggil di:
- zerotier_leave (line 282)
- zerotier_status (line 305)

Jika salah satu route diakses, akan crash dengan ImportError: No module named 'database'

## Perbaikan Saran
Ganti import menjadi:
from web.database import get_db

## Severity: MEDIUM
