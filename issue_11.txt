## Bug: Hardcoded Secrets di Source Code

**Severity:** LOW — credentials tersimpan di source code, bukan environment variable

**File:** `web/config.py` line 4-10, 13-14

### Root Cause
```python
DB_CONFIG = {
    'host': 'localhost',
    'user': 'radius',
    'password': 'radiuspass123',
    'database': 'radius_db'
}

RADIUS_SECRET = 'testing123'
```

### Impact
- Jika source code bocor (GitHub public, backup, laptop hilang), credentials terekspos
- Tidak bisa deploy ke environment berbeda tanpa edit source code
- Semua environment pakai credential sama

### Fix
Gunakan environment variable:
```python
import os
DB_CONFIG = {
    'host': os.environ.get('DB_HOST', 'localhost'),
    'user': os.environ.get('DB_USER', 'radius'),
    'password': os.environ.get('DB_PASSWORD'),
    'database': os.environ.get('DB_NAME', 'radius_db')
}
RADIUS_SECRET = os.environ.get('RADIUS_SECRET', 'testing123')
```

### Note
Repository GitHub saat ini PRIVATE, jadi risiko langsung rendah. Tapi best practice tetap gunakan environment variable.
